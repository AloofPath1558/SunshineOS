## 🚀 Overview

SunshineOS is a personal OS development project built to explore:

- 🐧 Linux system customization
- 💽 Disk image creation and partitioning
- ⚡ Boot process experimentation
- ⚙️ System configuration workflows
- 📦 OS deployment pipelines
- 🛠️ Custom Linux distribution development

This project is still under active development and is intended for **educational and experimental purposes**.

---

## ⚙️ Build / Usage

Depending on your environment, SunshineOS can be built and tested using tools such as:

- **Cubic** — Custom Ubuntu ISO builder
- **QEMU** — Virtual machine testing
- **VirtualBox** — Virtual machine testing
- **Linux shell tools** — System customization and automation

### 🛠️ Building SunshineOS

SunshineOS can be customized and rebuilt using **Cubic**.

The general workflow is:

1. Install **Cubic**
2. Start a new Cubic project
3. Select your **Ubuntu base ISO**
4. Customize the filesystem
5. Configure the desktop and system
6. Generate the final ISO
7. Test the ISO using **QEMU** or **VirtualBox**

## 🔧 Build Your Own SunshineOS Fork!

Want to create your own version of SunshineOS? **You can!** ☀️

Start from the **SunshineOS base ISO** and customize it to your own needs.

### 🛠️ Fork Workflow

1. Fork this repository
2. Download or obtain the **SunshineOS base ISO**
3. Install **Cubic**
4. Create a new Cubic project
5. Import the SunshineOS ISO
6. Customize the filesystem
7. Customize the desktop and system configuration
8. Generate your new ISO
9. Test it using **QEMU** or **VirtualBox**
10. Share your fork with the community!

> 💡 For more information, see the [**BUILD.md**](Docs/BUILD.md).
---
> 💡 **Tip:** SunshineOS is designed to be customizable. Feel free to experiment, modify components, change the desktop, and build your own vision of the system.
